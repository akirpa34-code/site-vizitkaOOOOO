# Сайт-визитка Владислава Дерябина

Персональная страница в эстетике сайтов начала 2000-х годов: тёмные панели с объёмными рамками, оранжевые акценты, повторяющийся полупрозрачный фон со смайликами и предоставленные автором изображения.

## Структура проекта

- `frontend/` — HTML, CSS, клиентский JavaScript и изображения.
- `backend/` — сервер Node.js + Express и обработчик формы обратной связи.

## Запуск

1. Установите Node.js.
2. Откройте терминал в папке `backend`.
3. Выполните `npm install`.
4. Выполните `npm start`.
5. Откройте в браузере `http://localhost:3000`.

Изображения находятся в `frontend/assets/`. Повторяющийся фон можно настроить в `frontend/styles.css`.


Дополнительно: `frontend/assets/VerityGIF.gif` — анимированная GIF в нижней части левой колонки; `frontend/assets/offtopic-sign.png` — знак внимания с удалённым фоном.
